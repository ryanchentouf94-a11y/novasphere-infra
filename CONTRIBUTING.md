\# Conventions NovaSphere

\- Une branche Git par changement.

\- Chaque changement passe par une pull request.

\- La pull request est relue avant merge sur main.

\- Un tag Git est créé à la fin de chaque séance.

\- Les fichiers tfstate ne sont jamais commités.

\- Les fichiers tfvars ne sont jamais commités.

\- Les clés privées et fichiers .pem ne sont jamais commités.

\- Les fichiers .env ne sont jamais commités.

\- Les inventaires générés ne sont jamais commités.

\- Les ressources sont détruites ou arrêtées en fin de journée.
